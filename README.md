# Head impact detection from kinematic data

Course mini-project, UE24CS352A Machine Learning.

An instrumented mouthguard records linear acceleration and angular velocity whenever it
sees a spike above 10 g. Many of those recordings are not head impacts: biting, chewing,
spitting or dropping the mouthguard also trigger it. This project trains a small
convolutional network (HIKNet, from the paper below) to separate real impacts from false
positives, and compares it with an SVM trained on handcrafted features.

Paper: Fanton, Gaudio, Ling, "Neural Network for Detecting Head Impacts from Kinematic
Data", CS229, Stanford, 2018.

## About the data

The paper's dataset (527 events recorded at Stanford with the Camarillo Lab mouthguard) is
not public, and the code that came with the paper does not include it. This repository
therefore uses **synthetic data** generated by `src/synthetic_data.py`.

- 527 events, 264 real impacts and 263 false positives
- each event is 199 time steps at 1000 Hz (50 ms before the trigger, 150 ms after)
- six channels: linear acceleration x, y, z (g), angular velocity x, y, z (rad/s)
- real impacts are smooth, low frequency pulses; false positives are short, noisy,
  high frequency bursts
- 30% of the events of each class are ambiguous: they mix in 0.5 to 1.0 times the
  behaviour of the other class

How the difficulty was set: the first version (8% ambiguous events, mixing strength 0.3
to 0.6) was too easy, with the SVM at 100% cross-validation accuracy and the CNN at 100%
on the test split. The settings above were chosen from a small set of candidates because
the SVM's cross-validation accuracy on the train + validation data (0.935) matched the
93.7% that the paper reports for its SVM on real data. The test split was not used to
choose them. The CNN had already been run on the first, easier version before this change.

Results on this data show that the pipeline works. They cannot be compared with the numbers
in the paper, which were measured on real recordings.

## Setup

Use Python 3.11 or 3.12 (TensorFlow does not install on every Python version).

Windows (PowerShell):

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt

macOS / Linux:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

Run every command below from the repository root with the environment active.

## Running

Check the model builds (prints the layer shapes):

    python -m src.hiknet

Then, in this order:

    python -m src.synthetic_data      # writes data/data.mat and data/labels.mat (already included)
    python -m src.eda                 # figures/example_traces.png, figures/mean_spectrum.png
    python -m src.svm_baseline        # SVM on handcrafted features -> results/svm_metrics.json
    python -m src.train_cnn --runs 5  # trains HIKNet 5 times -> results/cnn_metrics.json
    python -m src.evaluate            # results/comparison.md, figures/roc_pr.png
    python -m src.demo --plot         # classify events the model never saw

`python -m src.synthetic_data` replaces the data and deletes `results/split.json`, so run
the later steps again after it.

## Method

- Split: stratified 70% train, 15% validation, 15% test with a fixed seed, shared by both
  models. The test split is used only for the final numbers.
- Preprocessing: each channel of each event is standardized (mean 0, standard deviation 1
  over time).
- HIKNet: two Conv1D layers (150 filters, kernel 15, max pooling 2, dropout 0.4), one
  Conv2D layer (150 filters, kernel 3x15, stride 3x1), global average pooling, dropout
  0.4, sigmoid output. Adam, binary cross-entropy, early stopping on validation loss with
  patience 5.
- SVM baseline: 34 handcrafted time and frequency features, forward sequential feature
  selection, RBF SVM with C and gamma chosen by cross-validation. It is fitted on
  train + validation.
- Metrics: accuracy, precision, specificity, sensitivity, area under the ROC curve and
  under the precision-recall curve.

## Results

Test split, 80 events, synthetic data. HIKNet is the mean and standard deviation over
5 training seeds; the SVM is a single deterministic fit. One test event is 1.25 points of
accuracy, so small differences are within noise.

| Metric      | SVM   | HIKNet (5 runs) |
| ----------- | ----- | --------------- |
| Accuracy    | 91.2% | 91.8 +/- 0.6%   |
| Precision   | 94.6% | 92.0 +/- 0.9%   |
| Specificity | 95.0% | 92.0 +/- 1.0%   |
| Sensitivity | 87.5% | 91.5 +/- 1.2%   |
| AUC ROC     | 0.937 | 0.978 +/- 0.002 |
| AUC PR      | 0.962 | 0.980 +/- 0.002 |

The two models tie on accuracy. HIKNet ranks events better (higher AUC), which is
suggestive but not conclusive on 80 events. This differs from the paper, which reports a
larger gap on real data. Running the steps above regenerates `results/comparison.md` and
the figures.
